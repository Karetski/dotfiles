# ghostty

Installs the Ghostty terminal emulator via `ensure_brew_cask ghostty` and deploys its config to `~/Library/Application Support/com.mitchellh.ghostty/config.ghostty`.

## Configuration

| Setting | Value |
|---------|-------|
| Theme | Separate light/dark variants using Apple System Colors (adapts to macOS appearance) |
| Font | SF Mono Terminal, Medium weight, 11pt |
| Cursor | Block style |
| Shell integration | Cursor and sudo disabled; title enabled |
| Split divider | `#FF9100` (vibrant orange) — visible on both light and dark themes |
